# Persefoni GraphQL API

Persefoni is a climate management and accounting platform for enterprise carbon measurement. The API covers activity data ingestion, emission calculations, portfolio financed emissions (PCAF), disclosure reports, and benchmark comparisons.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Persefoni REST API
**Documentation:** https://www.persefoni.com/platform

- Reference: https://www.persefoni.com/product/integration-hub
